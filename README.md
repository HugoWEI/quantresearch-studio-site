# QuantResearch Studio — public validation website

A prelaunch landing page for original LaTeX document templates for quantitative careers and scientific research.

## Current status
- Prelaunch; no checkout or customer data collection is active.
- Paid template source files must **never** be committed to this public repository.

## Deployment
Enable **Settings → Pages → Deploy from a branch → main → /(root)**. The site then appears at https://hugowei.github.io/quantresearch-studio-site/ .
